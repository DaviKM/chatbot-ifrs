# Chatbot para WhatsApp - Processo Seletivo IFRS Campus Canoas

Este projeto consiste em um chatbot para WhatsApp desenvolvido em **Python**, com o objetivo de responder dúvidas de candidatos e ingressantes sobre o Processo Seletivo do **IFRS Campus Canoas**.

A aplicação utiliza uma arquitetura **RAG (Retrieval-Augmented Generation)**, realizando buscas em documentos oficiais do processo seletivo para fornecer respostas contextualizadas e mais precisas aos usuários.

## Tecnologias

- Python
- FastAPI
- LangChain
- Qdrant

## Funcionalidades

- Atendimento automatizado via WhatsApp.
- Consulta aos documentos oficiais do processo seletivo.
- Busca semântica utilizando banco vetorial.
- Respostas geradas com base nas informações recuperadas dos documentos.
