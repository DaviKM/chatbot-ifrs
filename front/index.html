Como funciona a indexação?

  • O arquivo PDF é lido página a página e seu texto é extraído.
  • O conteúdo é dividido em blocos semânticos (chunks) com sobreposição para preservar contexto.
  • Os chunks são vetorizados via modelo de embeddings e indexados no Qdrant.
  • Após o treinamento, o simulador de chat responderá dúvidas baseando-se nas informações desse documento.
